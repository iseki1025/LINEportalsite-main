# おつかい日和

`friend-game-otsukai-biyori.html` から起動する、通信なしで動くHTML5ゲームです。画面固有のCSS・状態遷移・純粋な問題生成/採点/保存処理をこのフォルダに隔離しています。

- `core/`: シード乱数、問題生成、採点、端末内設定/履歴
- `data/`: 30商品の情報と短いメッセージ
- `assets/`: 商店街3景、みのりさん3表情、30商品のオリジナルSVG
- `game.css`: `.ob-game` を起点にしたゲーム専用スタイル

通常モードはブラウザの暗号学的乱数、今日のおつかいは日本時間の日付と固定ソルトから問題を生成します。記録保存は初期OFFで、ONにした場合も `localStorage` のみを使います。
