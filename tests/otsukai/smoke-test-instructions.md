# ブラウザスモークテスト

ローカルHTTPサーバーをリポジトリ直下で起動し、`friend-game-otsukai-biyori.html` を実ブラウザで確認します。

1. タイトルから通常のおつかいを開き、のんびり・いつもの・チャレンジをそれぞれ3ラウンド完走する。
2. チャレンジ第3ラウンドで変更前の商品を選ばず、追加商品を正解として選択できることを確認する。
3. 今日のおつかいを開き、3ラウンド完走する。同じ日付で再挑戦したとき同じ問題になることを確認する。
4. メモ確認、レジの見直す、設定、Escape、途中のゲーム一覧確認、音OFF、演出を控えめにする、履歴保存OFFを確認する。
5. `320x568 / 360x800 / 390x844 / 430x932 / 768x1024 / 1280x800` で横スクロール、ボタン重なり、商品名の欠落がないことを確認する。
6. タイトル、メモ、看板、売り場、結果の5状態をスクリーンショットに保存する。

採点は時間・寄り道の失敗・ヒント使用で減点せず、端末外への通信が発生しないことも確認します。
